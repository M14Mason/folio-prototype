# Folio prototype

A clickable navigation prototype for Folio, a portfolio platform that builds and maintains an artist's site from the folder they already use.

**Live site:** https://m14mason.github.io/folio-prototype/

This is a prototype only. Nothing is saved, uploaded, published or charged; actions show a "Prototype mode" message.

- `index.html` is the whole app (GSAP and Three.js load from cdnjs).
- `examples/` holds the five sample homepages and their screenshots.
- Photos are from Unsplash. Artist names and prices shown on the site are illustrative.
